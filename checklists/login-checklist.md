# Login Checklist

## Functional Testing

- [ ] Login with valid username and valid password
- [ ] Login with invalid username
- [ ] Login with invalid password
- [ ] Login with empty username
- [ ] Login with empty password
- [ ] Login with both fields empty
- [ ] Verify error message for invalid password
- [ ] Verify user is redirected after successful login
- [ ] Verify user cannot access secure page without authentication
- [ ] Verify Logout works correctly
